# Frontend - Gestion de Gastos Personales

Frontend desarrollado con HTML, CSS y JavaScript (SPA vanilla) sobre Vite.

## Scripts

- `npm run dev`: inicia servidor de desarrollo
- `npm run build`: genera build de produccion
- `npm run preview`: previsualiza build
- `npm run lint`: ejecuta ESLint

## Stack

- JavaScript (SPA con History API)
- Bootstrap 5
- Chart.js
- Vite

## Estructura actual

- `src/main.js`: router cliente, render de vistas, eventos y estado de interfaz
- `src/App.css`: estilos generales de layout y pantallas
- `src/index.css`: estilos base
- `src/components/dashboard/dashboard-widgets.css`: estilos de widgets del dashboard
- `public/images/imagen1.jpeg`: imagen de fondo para landing/login
